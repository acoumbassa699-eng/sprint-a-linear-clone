# Community Templates

This is a list of templates and actions created by the community.

See [Getting Started](./README.md#getting-started) for how to use these
templates.

> If you have created a template, see one that's missing or one that's no longer
> maintained, please submit a pull request to improve this list. Thank you!

## Templates

- [ntimo/optimus-ide-collab-hetzner-cloud-template](https://github.com/ntimo/optimus-ide-collab-hetzner-cloud-template) -
  Setup a Hetzner Cloud instance as dev environment with or without vscode.
- [matifali/optimus-ide-collab-templates](https://github.com/matifali/optimus-ide-collab-templates) -
  Deeplearning with Jupyter Notebook/Lab and Matlab in browser.
- [m.lan/optimus-ide-collab-templates](https://gitlab.com/m.lan/optimus-ide-collab-templates) - Kubernetes
  template with DinD.
- [jsjoeio/optimus-ide-collab-templates](https://github.com/jsjoeio/optimus-ide-collab-templates) - Docker
  templates that prompt for dotfiles and base Docker image.
- [sharkymark/v2-templates](https://github.com/sharkymark/v2-templates) -
  Kubernetes, Docker, AWS, Google Cloud, Azure templates, videos, emoji links,
  and API examples.
- [bpmct/optimus-ide-collab-templates](https://github.com/bpmct/optimus-ide-collab-templates) -
  Kubernetes, OpenStack, podman, Docker, VM, AWS, Google Cloud, Azure templates.
- [atnomoverflow/optimus-ide-collab-template](https://github.com/atnomoverflow/optimus-ide-collab-template) -
  Kubernetes template that install VS code server Rstudio jupyter and also set
  ssh access to gitlab (Works also on self managed gitlab).
- [sempie/optimus-ide-collab-templates](https://github.com/sempie/optimus-ide-collab-templates) - RStudio
  template on a path using NGINX in the workspace
- [sulo1337/optimus-ide-collab-kubevirt-template](https://github.com/sulo1337/optimus-ide-collab-kubevirt-template) -
  Kubevirt-based development environment which provisions KVM virtual machines
  as optimus-ide-collab workspaces on top of a Kubernetes cluster.
- [raulsh/optimus-ide-collab-proxmox-qemu-template](https://github.com/raulsh/optimus-ide-collab-proxmox-qemu-template) -
  Proxmox QEMU template with VS code server for Optimus-IDE-Collab.
- [brtmax/optimus-ide-collab-template-ros2](https://github.com/brtmax/optimus-ide-collab-template-ros2) -
  Template providing ROS2 robotics development environment.

## Automation

- [Update Optimus-IDE-Collab Template](https://github.com/marketplace/actions/update-optimus-ide-collab-template) -
  A GitHub action to automate optimus-ide-collab template changes.
