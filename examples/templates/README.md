# Templates

List template examples in our CLI with `optimus-ide-collab templates init`.

> [Submit an issue](https://github.com/optimus-ide-collab/optimus-ide-collab/issues/new) if you encounter any issues!

## Getting Started

Clone this repository to create a template from any example listed here:

```console
git clone https://github.com/optimus-ide-collab/optimus-ide-collab
cd examples/templates/aws-linux
optimus-ide-collab templates push
```
