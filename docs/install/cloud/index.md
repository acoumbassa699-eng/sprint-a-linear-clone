# Cloud Platforms

We provide install guides and example templates for deploying Optimus-IDE-Collab to your
cloud of choice.

<div class="tabs">

## AWS

We publish Optimus-IDE-Collab Community Edition on the AWS Marketplace. Follow the tutorial here:

- [Install Optimus-IDE-Collab Community Edition from AWS Marketplace](./aws-marketplace.md)

Alternatively, install the [CLI binary](../cli.md) on any Linux machine or
follow our [Kubernetes](../kubernetes.md) documentation to install Optimus-IDE-Collab on an
existing Kubernetes cluster.

For EKS-specific installation guidance, see the [AWS section in Kubernetes installation docs](../kubernetes.md#aws).

## GCP

We publish a GCP Marketplace listing with Optimus-IDE-Collab pre-installed. Follow the
tutorial here:

- [Install Optimus-IDE-Collab on GCP Compute Engine](./compute-engine.md)

Alternatively, install the [CLI binary](../cli.md) on any Linux machine or
follow our [Kubernetes](../kubernetes.md) documentation to install Optimus-IDE-Collab on an
existing GKE cluster.

## Azure

Use the following guide to run Optimus-IDE-Collab on an Azure VM:

- [Install Optimus-IDE-Collab on an Azure VM](./azure-vm.md)

Alternatively, install the [CLI binary](../cli.md) on any Linux machine or
follow our [Kubernetes](../kubernetes.md) documentation to install Optimus-IDE-Collab on an
existing GKE cluster.

## Other

Is your cloud missing? Check [unofficial](../other/index.md) install methods or
install the [standalone binary](../cli.md).

</div>
